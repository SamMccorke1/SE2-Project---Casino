# Sprint 1 Report

## Overview
The primary objective for this sprint was implementing the user authentication system. However, following a mid-sprint technical assessment, the team shifted focus toward establishing a robust architectural foundation. This pivot ensured that database migrations and the global UI framework were finalized before layering on more complex security features.

Overall pace was mildly impacted as the team adjusted to working together.

## Key Achievements & Activities
While the development pace was introductory, the team successfully initialized the core components of the application:

- Executed initial database migrations to establish the primary schema.
- Defined the structural outline for the site to ensure scalability.
- Developed the home page architecture, establishing the visual identity and navigation flow for the web application.
- Initiated backend logic for the login system, laying the groundwork for secure user sessions.
- Began early-stage development on the primary game modules (Blackjack and Poker), focusing on initial logic and state management.

## Challenges
No significant technical blockers were encountered during this period.
