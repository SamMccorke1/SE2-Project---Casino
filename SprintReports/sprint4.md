Sprint Goal
The goal of this sprint was to transform our casino website from a simple prototype into a functional multiplayer casino experience. The team focused on implementing a shared lobby system that allows multiple players to interact in real time, improving the user interface, strengthening authentication and database systems, and merging additional games into the casino platform. By the end of the sprint, the team aimed to have a stable and visually polished blackjack experience that could support multiple users and prepare the project for final testing and presentation.

PBIs Chosen for the Sprint
• Multiplayer blackjack functionality
• UI improvements and homepage redesign
• User authentication system
• Database system integration
• Merging of additional casino games

Sprint Planning Activity Summary
During the sprint planning session, the team discussed the main goals for the sprint and identified which PBIs should be prioritized to prepare the project for demonstration. Each team member volunteered or was assigned tasks based on their strengths and familiarity with different parts of the project such as frontend development, backend logic, authentication systems, or database management.

Sprint Tasks
Task 1
Task Owner: Samuel McCorkel
Task Title: Multiplayer Blackjack Lobby Implementation
Task Description:
Developed the multiplayer lobby system that allows up to four players to join the same blackjack table. Implemented the shared service that synchronizes gameplay actions such as dealing, hitting, and standing so that all players see updates in real time.
Task Status: Complete
Challenges Faced:
Blazor component naming conflicts and file-locking issues during development made debugging difficult. Synchronizing player state across multiple clients also required refactoring some backend logic.
Lessons Learned:
Refactoring backend services early improves maintainability. Careful management of component naming and service architecture helps prevent conflicts in Blazor applications.
Planned Time: 6 hours
Actual Time: 9 hours
